# M0 设计简报 · 3.5 寸修订版（在 brief-m0.md 之上的差量）

> 用户实机测试后确认：副屏物理尺寸 **3.5 英寸**（不是之前假设的 7 寸），面板 1920×1080，macOS 逻辑 960×540。用户在三档字号比对里选了 **2x**。
> 本文件只写与 `brief-m0.md` 不同的地方；没提到的规则、禁用项、五态、动效、评审后修订全部沿用。

## 新的几何

| 项 | 值 |
|---|---|
| 设计画布 | **480×270 CSS px**，固定，不滚动 |
| 渲染 | 画布整体 `zoom: 2` 铺满 960×540 逻辑分辨率；1 CSS px = 4×4 物理像素 = 0.16 mm |
| 观看距离 | 桌面座位，约 50–60 cm |
| 参照 | 16px 在这块屏上是 2.6 mm，相当于手机正文在 30 cm 处的大小；所以只有大数字和一行放大的标题能在座位上真正读清，其余都是「扫一眼能认」 |

## 字号下限（CSS px，画布坐标）

- 任何文本 ≥12px；标签 12–13px
- 最新一条事件的标题 ≥16px，**单行**，省略号截断
- 主数字（5h 已用 %）≥44px
- 行高 ≥28px（鼠标极少用）
- 数字仍用 IBM Plex Mono tabular；标签仍用 Inter + ss03

## 内容预算（这是核心：砍到四分之一）

每块屏只回答两个问题：三个 agent 还剩多少额度；谁刚做完或在等我。按此预算，多一个元素就要有理由。

**三块额度瓦片**（横排，各约 148px 宽）
- 保留：agent 名（13px）、状态点（idle / running 脉冲 / attention）、5h 已用 %（≥44px）、重置倒计时（12–13px，`2h26m` 样式）
- 降级：7d 窗只允许一个 12px 的次级数字或一条 3px 细 bar，V2 可以完全不显示
- ZCode 未连接：只留「未连接」两字 + 一行 12px 原因；「怎么接」那句移到托盘菜单，不占屏
- error：一行 12px，原因 + 下一步压成一句

**事件区**（瓦片下方，剩余高度约 80–90px）
- 只保留 **1 条放大的最新事件**：agent 徽记 + 标题（≥16px 单行）+ 相对时间（12px）
- 最多再加 **1 行** 14px 的次新事件；放不下就不放
- 去掉「另 N 条更早」、去掉未读计数文字；未读只靠最新行本身的强调表达
- attention 出现时，最新事件行本身变成 attention 行（不再另起 strip），标题前缀「等待你」

**顶部**
- 时钟 12px 放右上角；如果高度预算不够，时钟可以并入最新事件行右侧
- 品牌字「AGENT MONITOR」删除，3.5 寸上它没有信息

## 三个变体在新画布上的轴（沿用原轴，各自决定砍什么）

- **V1 Ledger**：数字优先。瓦片 = 名 + 44–52px 百分比 + 倒计时 + 一条 3px 的 5h bar；7d 作 12px 次级数字。
- **V2 Gauge**：形状优先。仪表弧缩到 56–64px，弧内只放百分比或只放倒计时二选一，另一项放弧旁；7d 不显示。
- **V3 Strip**：时间优先。三条时间带**竖向堆叠**（每条约 44px 高：名 + 判语 + %，带高 8–10px），事件区压到一行。V3 的判语文字（「会提前用尽」）保留但压到 12px。

任意两个变体的差别仍要能一句话说清；三者都要完整支持 7 种状态。

## 原型文件的改法

- 仍是 `design/variations.html` 单文件，覆盖原文件（旧版由 git 历史保留，先 `git add` 一次再改）
- stage 改为 480×270 画布，外层 `zoom: 2`，harness 里显示为 960×540；控制栏不变
- 截图仍输出 960×540 @2x（即 1920×1080 物理像素，与面板一一对应）：`design/shots/v{1,2,3}-{populated,attention}.png`，覆盖旧图
- Playwright 21 组合检查全部按新画布重跑，并保留评审返工后新增的断言（轨道 ≥3:1、attention accent ≤2、heading ≥5、loading role=status）
- 上一轮评审的 B/Q/P 修复全部沿用到新画布，不许回退
- `design/review/00-designer-notes.md` 追加「3.5 寸版」一节：砍了什么、为什么、每个变体一句 caption、推荐

## 不要做

- 不要把 960×540 的布局按比例缩小了事；那正是用户觉得字小的原因
- 不要加滚动、不要加翻页
- 不要为了塞下内容把任何文本压到 12px 以下
