# M0 v2 设计简报 · 用户实机反馈第二轮（在 brief-m0-rotation.md 之上的差量）

> 用户看过 M1/M2 实机后提出五条改动。几何、字号下限（≥14px）、accent 纪律、五态、手动切换、纯净模式全部沿用。画布仍按 480×270 与 480×320 两种都要能跑。

## 改动清单

### 1. 事件页改为「session 列表」，至少两页，显示最后更新时间

- C 页拆成 **C1、C2** 两页，每页 4 行，共 8 个 session；行结构不变（agent 徽记、标题单行省略、时间、ack）。
- 每行的时间是**最后更新时间**（最后一条消息 / 最后一次状态变化），不是开始时间；running 的行时间逐秒走（「刚刚」→「1 分钟前」），完成的行显示完成时刻。
- running 的 session 排最前，其次按最后更新时间倒序。
- 未读、attention 的表现不变；C1 满 4 行才溢出到 C2；C2 为空时跳过不轮播。

### 2. B 页进度条上不再显示判语，改显示用得最多的模型

- 删掉「按这个速度用不完 / 会提前用尽」整句判语。
- 原判语位置显示该 agent **当前窗口内用得最多的模型名**（例：`gpt-6-astra`、`Fable 5.1`、`GLM-5.3-Flash`），14px、`--mute`，mono 或 sans 由你定（模型名混合大小写与数字，倾向 sans）。
- 「够不够撑到重置」这个信息不丢：由时间带上填充与「现在」游标的落差承担，不再用文字复述。

### 3. 新页 D · 每日用量热力图（GitHub 风格）

- 回答的问题：最近几周我用得多不多、哪几天最猛。
- 一张 7 行（周一到周日）× N 列（周）的格子图，格子 12–14px、间隙 2px，N 由画布宽度决定（480 宽约放 26–28 周）；右下角当前周。
- 颜色：五档，用 raycast 的 surface 阶梯做 0 档，其余四档用**同一色相**的明度阶（不要 GitHub 的绿；用 `--ink` 的透明度阶或 `--accent-blue` 的明度阶，选一个并说明），无渐变。
- 顶部一行：`每日用量 · 近 N 周`，右侧三个 agent 的图例小点（身份色）——但格子本身**不按 agent 分色**，只按总量分档；agent 分量用格子下方一条 14px 的说明行表达当天 top agent（可选，放不下就不放）。
- hover / 焦点格子显示日期与数值（tooltip 14px），键盘 ←→ 可移动焦点。
- 数据：主进程给 `usage: { days: [{date, total, byAgent:{codex,claude,zcode}}] }`；单位先按「请求次数」统一（三家都拿得到），token 与费用留字段。原型里用真实近 8 周数据（executor 会提供 fixtures，暂时先用 `design/fixtures/usage.json`，若不存在就合成并标注）。

### 4. 新页 E · 今日 AI 大事（AIHOT）

- 回答的问题：今天 AI 圈最值得看的 5 件事。
- 5 条，每条：序号（tabular）、标题（≤2 行，16px，`text-wrap: balance`）、来源与相对时间（14px `--mute`）。第 1 条不放大，五条等权——这一页是阅读不是扫视。
- 顶部 `今日 AI · AIHOT`，右侧更新时间；底部一行 14px 署名「数据来源：AIHOT」（使用规则要求）。
- 五态：loading 骨架 5 行；empty「今天还没有精选」；error「AIHOT 暂时连不上 · 30 分钟后重试」；edge：标题 80 字、来源名超长。
- 数据：主进程给 `news: { updatedAt, items: [{title, source, url, at, summary?}] }`；原型先用 `design/fixtures/news.json`（若无则用 5 条真实感的占位并标注）。
- 与轮播的关系：不打断、不响铃、不计未读。

### 5. 横向压缩补偿

- 副屏在 960×540 模式下被面板缩放器横向压 15.6%（EDID 原生 960×640）。**用户用校准页实测：系数 1.19 时为正圆。** 原型加一个 `--panel-x` 变量（默认 1.19；960×640 模式下为 1.0），stage 的 zoom 改为 `transform: scale(2 * panelX, 2)`，画布逻辑宽度相应变为 `480 / panelX` 取整（panelX 1.19 → 403px），所有布局在 403×270 与 403×320 也不能溢出。
- 控制栏加一个 `panel-x` 滑块（1.00–1.25，步进 0.01，写 localStorage），纯净模式下按 `[` / `]` 调 ±0.02 并在右上角闪显 1 s 数值。
- 用户会用 `design/tools/aspect-test.html` 的圆定出系数；Electron 版会把这个系数存到配置。

### 6. 页面指示点位置

- 用户实机反馈：指示点目前贴在右下角，与瓦片边框重合。改为**水平居中**放在画布底部，并比现在再往下挪一点（底边距 6px 左右，但要保证不被裁切）；点与点间距不变。
- 指示点下方不再有任何元素；C 页最后一行与指示点之间至少留 8px。

### 7. 进度条用各 agent 的身份色（用户 2026-09-14 晚追加）

- B 页三条时间带的**填充色**改为该 agent 的身份色：Codex `--id-codex`（charcoal）、Claude `--id-claude`、ZCode `--id-zcode`；轨道仍 `--ash`，填充末端的 2px `--canvas` 缺口保留，边界不依赖色差。若 A 页或其它页存在额度 bar，同样处理。
- 这是用户明确要求，覆盖「身份色只用于小面积」的原则；身份色是分类色，不计入 accent。
- **阈值表现调整**：warn / danger 时不再把整条填充改成黄 / 红（否则与身份色冲突），改由百分比数字变色 + foot 的判语文字与警示图标承担；三家在 ok 级的视觉差异只来自身份色。
- 新增 token：`--quota-fill-codex / -claude / -zcode`，在 tokens.css 的项目层定义并引用身份色，不复制 hex。
- 对比度：Claude 橙、ZCode 蓝叠在 `--ash` 轨道上约 1.7:1，靠缺口机制传边界（R3-02 的结论），不用再补形状差；数字与文字的对比度不变。

## 轮播

页序 A → B → C1 → C2 → D → E → A。停留仍每页 60 s（token），C2 空时跳过。打断规则不变（新事件跳到 C1）。指示点从 3 个变为最多 6 个。
