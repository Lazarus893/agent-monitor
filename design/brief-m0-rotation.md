# M0 设计简报 · 轮播版（在 brief-m0.md、brief-m0-35.md 之上的差量）

> 用户提出：3.5 寸屏不必把所有信息挤在一屏，可以分多页自动轮播。本文件定义轮播版的页面、节奏与打断规则。几何仍是 480×270 画布 × zoom 2；字号下限、五态、accent 纪律、评审后修订、第一轮 15 条修复全部沿用。
> `brief-m0-35.md` 里「不要加翻页」一条作废，改为本文件的规则。

## 为什么轮播，以及它的坑

一屏只回答一个问题，字号就能再放大一档。代价是「扫一眼时想看的不在屏上」。所以轮播必须满足：总览页回归得足够快；事件能打断轮播；任何时刻看得出当前是第几页。

## 三页

三个原变体各自成为一页，不再互相竞争：

| 页 | 回答的问题 | 内容 | 来源 |
|---|---|---|---|
| **A 总览** | 还剩多少 | 三块瓦片横排：agent 名、状态点、5h 已用 %（**≥60px**）、倒计时（13px）。7d 不显示。ZCode 未连接只显示「未连接」 | V1 Ledger（可选 V2 的弧作为 A 页的风格开关，默认关） |
| **B 额度详情** | 够不够撑到重置 | 三条竖向时间带：名、判语（12–13px）、5h %、7d %（12px）、带高 ≥10px、「现在」游标、重置刻度。ZCode 未连接一行说明原因 | V3 Strip |
| **C 事件** | 谁刚做完 | 最新 3–4 条：第一条放大（标题 ≥18px 单行 + agent 徽记 + 相对时间），其余 14px 行；未读用最新行强调表达，不要计数文字 | 原事件流 |

## 字号下限（依据 `design/review/04-verify-hierarchy-35.md` 的物理可读性推算修订，覆盖 brief-m0-35.md 的下限）

复核按 0.16 mm/px、55 cm 距离实算：44–48px 数字「座位上能读」，13–18px「只能认」，**12px 全部「认不出」**。轮播腾出了空间，信息层整体抬一档：

| 元素 | 下限 | 说明 |
|---|---|---|
| 任何文本 | **14px** | 12px 与 13px 全部废除；页面指示点不是文本，不受限 |
| 时钟 | 14px | mono |
| A 页 5h 百分比 | **≥64px** | 三块瓦片没有 7d 和 bar 之后，高度够 |
| A 页 agent 名 | 16px | |
| A 页倒计时 | **≥18px** mono | 它是简报点名保留的核心信息，12px 时分不清 2h22m 与 2h26m |
| B 页百分比 | ≥20px mono | 5h 主、7d 次可 16px |
| B 页判语 | ≥14px | 「落后时钟 30 点 · 用不完」压成一句 |
| C 页最新事件标题 | **≥20px** 单行 | |
| C 页其余事件标题 | 16px | 时间 14px mono |
| 空态 / error 的原因句 | 14–16px | 一句话，不再两段 |
| attention 页 | 「等待你」≥24px，说明句 ≥18px | 整屏只为这一件事 |

## 节奏

- 默认顺序 A → B → C → A …
- 停留：**每页 60 s**（用户 2026-09-14 实机反馈原 10/6/6 s 太快）。写成 tokens：`--dwell-a`、`--dwell-b`、`--dwell-c`，默认都是 60 s
- 「空闲加速」规则作废，不再随空闲缩短停留
- 有更新就主动切换：新事件立即跳到 C 页并停满一个 dwell（60 s），再来一条重新计时；attention 接管整屏直到解除。这两条打断规则见下节，优先级高于定时轮播
- 切页：横向滑动 300 ms，`--ease-standard`；`prefers-reduced-motion` 与控制栏开关下直接切换，无动画
- 页面指示：右下角三个 4px 圆点，当前页 `--ink`，其余 `--ash`；这不算 accent

## 打断规则（优先级从高到低）

1. **attention（等待你批准 / 输入）**：一张专用整屏页接管——agent 名、「等待你」、一句话说明在等什么、等了多久。轮播暂停，直到该状态消失（原型里用 ack 或再点一次「模拟」来解除）。
2. **新事件完成**：立即切到 C 页并停满一个 dwell（60 s），新行从顶部推入；期间再来一条就重新计时。播提示音一次。
3. **running**：不打断，只在 A 页状态点脉冲、C 页顶部一行「进行中」。
4. 打断结束后从 A 页恢复轮播。

## 纯净模式（用户在副屏上还原最终效果用）

浏览器的标签栏、地址栏和原型自带的控制栏都会破坏副屏上的观感，所以原型要能一键变成「只有画布」：

- 打开 `variations.html?pure=1`，或在任何时候按 `P` 键，进入纯净模式：控制栏与说明文字全部隐藏，`body` 背景就是 `--canvas`，画布以 zoom 2 铺满视口并居中；同时调用 Fullscreen API 让浏览器进入全屏（标签栏、地址栏、菜单栏消失）
- 纯净模式下自动轮播强制开启，`localStorage` 里的手动选页忽略
- `Esc` 或再按 `P` 退出，回到带控制栏的调试视图
- 因 Fullscreen API 必须由用户手势触发，`?pure=1` 打开时先显示一行 14px 提示「按任意键进入全屏」，按键后再请求全屏；提示只出现这一次
- 纯净模式下键盘 ack 仍可用；页面指示点保留

## 手动切换（用户 2026-09-14 定稿时追加）

自动轮播之外，用户要能随时手动翻页：

- **触发方式**：① 键盘 `←` / `→` 切上一页 / 下一页，`↑` 或 `Home` 回 A 页；② 点击右下角指示点直接跳页（指示点热区放大到 24×24，视觉仍是 4px 点）；③ 点击画布左右各 15% 宽的边缘区切页，无常驻控件，鼠标移入该区域时显示一个 24px 的 monoline chevron，2 s 无移动即隐藏；④ Electron 版另加全局快捷键 `⌃⌥←` / `⌃⌥→` / `⌃⌥↑`，不需要窗口聚焦
- **手动之后的节奏**：手动切页后自动轮播暂停 120 s（token `--manual-hold`），期间指示点左侧显示一个 14px 的「‖」标记；120 s 无操作后从当前页继续轮播
- **打断优先级不变**：手动暂停期间来了新事件仍跳 C 并重新计时，attention 仍接管整屏
- attention 接管页不能被手动切走（它需要被处理），但可以按 Enter ack 解除
- 纯净模式下以上全部可用；调试视图的控制栏保留原有页切换按钮

## 原型文件的改法

- 仍是 `design/variations.html` 单文件，覆盖（先把 3.5 寸单屏版另存为 `design/variations-35-single.html`，截图移到 `design/shots/35-single/`）
- 控制栏改为：页切换 A / B / C / attention 页（手动查看用）、「自动轮播」开关（默认开）、状态切换（沿用 7 种）、「模拟新事件」、「模拟等待批准」、reduced-motion
- 轮播计时可视化：控制栏里显示当前页与剩余秒数，方便验证节奏；这属于工具，不进画布
- `localStorage` 记住轮播开关与手动选中的页
- 截图：`design/shots/page-a.png`、`page-b.png`、`page-c.png`、`page-attention.png`（960×540 @2x）
- Playwright：4 页 × 7 状态跑溢出、字号下限、accent 计数、轨道对比度、heading、role=status；另加节奏断言：A 停留 ≥ B、C；新事件后 200 ms 内 C 页可见；attention 下轮播停止
- 笔记追加「轮播版」一节：每页一句 caption、节奏取值理由、未验证项

## 不要做

- 不要在任何页上恢复被砍掉的内容（品牌字、cwd、1mo 窗、「另 N 条更早」）
- 不要让任何一页停留少于 4 s
- 不要为了页数好看而加第四页；三页加一张 attention 专用页就是全部
