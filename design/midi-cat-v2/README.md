## 现状与改进

现有 src/renderer/midi-sprites.ts 使用 16×14、5 色字符帧。绿色眼睛只有单色点，缺少瞳孔；白色嘴胸占比偏大，削弱胸环纹；没有标志性粗环尾；typeL/typeR 通过省略底行一侧的爪子制造动作。

照片中的识别锚点：宽圆脸、黄绿色虹膜和深色瞳孔、额头 M 纹、颊侧黑纹、胸前多道环纹、身体大块回旋纹、粗环尾、浅色下巴与爪端。侧面及背面不可见的细节属于合理补全，并非照片已确认的精确花纹。

## 三个方向

- [01 圆脸桌面伴侣](01-round-companion.png)：坐姿、宽脸、亲近的表情，最适合现有键盘场景。推荐作为项目主形象。
- [02 原照比例](02-photo-faithful.png)：站姿与竖尾最贴近照片，适合走动、伸懒腰和蜷睡。
- [03 复古小比例](03-pocket-retro.png)：更紧凑的头身比例，适合小尺寸显示；落地时还需要进一步减少像素和细节。

每套上方为正、侧、背视图，下方为八个动作姿态。它们是像素风设计图，生成结果并非严格 24/32/48 像素原生网格，也不是可以直接裁切播放的 sprite atlas。不要直接缩成旧版 16×14：眼睛和胸纹会糊掉。

## 动作设计与落地节奏

| 动作 | 建议帧序列 | 时机与节奏 |
|---|---|---|
| 待机 | 正常 → 胸口抬 1 格 → 正常 | 约 2.4 秒；幅度很小 |
| 慢眨眼 | 睁眼 → 半闭 → 闭眼 → 半闭 → 睁眼 | 约 320 ms；间隔 3–7 秒 |
| 打字 | 爪子抬起 → 压键 → 回位，左右交替 | 输入脉冲触发，120–180 ms 一次；两只爪始终存在，胸与脸不抖 |
| 抬头 | 视线先上移 → 下巴抬 1 格 → 定住 | 沿用停笔 4 秒触发；不循环点头 |
| 尾尖摆动 | 中 → 左 → 中 → 右 → 中 | 1.6–2.4 秒；只弯末端，尾环跟随尾巴 |
| 耳朵轻动 | 正常 → 单耳偏 1 格 → 正常 | 偶发，约 240 ms |
| 趴下睡 | 坐姿 → 收爪 → 降低身体 → 下巴落爪 → 闭眼 | 沿用停笔 5 分钟；过渡约 800 ms，之后缓慢呼吸 |
| 伸懒腰 | 前爪前伸 → 胸口下压、臀部抬起 → 回坐 | 醒来时偶发，约 1.2 秒 |
| 小跳 | 蹲低 → 上移 → 落地 → 回位 | 沿用每 500 字里程碑，约 480 ms |
| 走动 | 左前/右后迈步 → 接地 → 右前/左后迈步 → 接地 | 扩展场景可用；02 的 STEP 1/2 差别偏小，落地需重画交替腿 |

建议采用 01 的正面脸型和坐姿，参考 02 的尾巴与身体花纹；正式制作时在统一像素网格上绘制，固定脸宽、瞳孔、M 纹和胸环定位。与当前 224×128 场景一起检查尺寸及键盘遮挡，不能直接沿用 CAT_PAW_ROW=11。

减少动态效果设置下保留状态切换，关闭呼吸位移、尾摆与小跳。以上为设计规格；本次没有更改程序动作逻辑。
